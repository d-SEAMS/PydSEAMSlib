* The paper

If you use ~pydseams~, ~dseams~, the ~seams~ CLI, or Lua ~dseams~ in
published work, please cite the d-SEAMS paper:

#+begin_export rst
Goswami, R.; Goswami, A.; Singh, J. K.
*d-SEAMS: Deferred Structural Elucidation Analysis for Molecular
Simulations.*
*Journal of Chemical Information and Modeling* **2020**, *60* (4), 2169–2177.
:cite:`goswamiDSEAMSDeferredStructural2020`
#+end_export

DOI [[https://doi.org/10.1021/acs.jcim.0c00031][10.1021/acs.jcim.0c00031]].

BibTeX entry:

#+begin_src bibtex
@article{goswamiDSEAMSDeferredStructural2020,
  title = {d-SEAMS: Deferred Structural Elucidation Analysis for Molecular Simulations},
  author = {Goswami, Rohit and Goswami, Amrita and Singh, Jayant K.},
  journal = {Journal of Chemical Information and Modeling},
  year = {2020},
  volume = {60},
  number = {4},
  pages = {2169--2177},
  doi = {10.1021/acs.jcim.0c00031}
}
#+end_src

* The software

~pydseams~ is the Python bindings package in
[[https://github.com/d-SEAMS/PydSEAMSlib][PydSEAMSlib]], built on
the [[https://github.com/d-SEAMS/seams-core][seams-core]] C++ engine.
Suggested acknowledgement text:

#+begin_src text
Ice classification used pydseams, the Python bindings for the
d-SEAMS engine (https://github.com/d-SEAMS/PydSEAMSlib),
following Goswami, Goswami, and Singh, Journal of Chemical Information
and Modeling 2020 (DOI 10.1021/acs.jcim.0c00031).
#+end_src

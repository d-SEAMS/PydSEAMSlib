#+TITLE: MDAnalysis, OVITO and notebooks
#+OPTIONS: toc:nil num:nil

~pydseams.adapters~ connects d-SEAMS to MDAnalysis, OVITO, and ASE
pipelines.

* MDAnalysis

~IceStates~ is an ~AnalysisBase~ subclass over an oxygen
~AtomGroup~; ions can be passed as a second ~AtomGroup~ and are read
against the water cage assignment. Boxes must be orthorhombic.

#+begin_src python
import MDAnalysis as mda
from pydseams.adapters import IceStates

u = mda.Universe("brine.gro", "brine.xtc")
an = IceStates(u.select_atoms("name OW"), ions=u.select_atoms("name NA CL")).run()
an.results.states        # frames x oxygens, codes in an.results.state_names
an.results.features      # frames x len(an.results.names)
an.results.ion_states    # frames x ions, codes in an.results.ion_state_names
#+end_src

* OVITO

~ice_states~ is an OVITO Python modifier function. Append it to a
pipeline and colour by the ~Ice state~ particle property (0 water, 1
cubic, 2 hexagonal, 3 mixed; ~-1~ outside the selected oxygen type).

#+begin_src python
from functools import partial
from ovito.io import import_file
from pydseams.adapters import ice_states

pipeline = import_file("dump.lammpstrj")
pipeline.modifiers.append(partial(ice_states, oxygen_type=1, cutoff=3.5))
data = pipeline.compute()
print(data.particles["Ice state"][...])
#+end_src

Triclinic OVITO cells pass through as LAMMPS bound spans and tilts.

* Command line

With the ~seams~ CLI from seams-core,
~seams cages dump.lammpstrj --per-atom labelled.lammpstrj~ writes a
dump frame with a ~cage~ column (0 water, 1 hexagonal cage, 2
double-diamond cage, 3 both); ~fingerprint~ writes ~class~ or
~label~ and ~ions~ writes ~state~ for any trajectory visualiser.

* Notebook

~notebooks/classify_ice.ipynb~ installs ~pydseamslib~, fetches a frame
of the cubic mW lattice, and runs cage assignment, CHILL+, and
topological fingerprinting in Google Colab.

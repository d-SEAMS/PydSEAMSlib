# History

The project started in 2023 under the name `PySeams`. Because that name
could not be registered on PyPI due to naming similarities, the
distribution switched in 2024 to its current name, `PydSEAMSlib`
(`pydseamslib`).

## Funding

Alongside volunteer development, the d-SEAMS project received Google
Summer of Code (GSoC) funding to build the Python bindings.

### 2023

This project started under d-SEAMS's participation with the Python
Software Foundation (PSF) in the
[2023 Google Summer of Code programme](https://summerofcode.withgoogle.com/programs/2023/projects/WAft7HXq).
